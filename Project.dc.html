ARCHITECTURE — AGENTIC INTERACTION LAYER

The manager agent decomposes each request into sub-tasks and picks the specialist for each. For every sub-task, the retrieval gate embeds it and scores all MCP method definitions in Qdrant by cosine similarity; only the top-k methods above threshold τ are handed to that specialist — not the full tool catalogue — keeping each agent call token-efficient. If nothing clears τ, a small general model answers directly.
